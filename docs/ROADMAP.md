# Roadmap

Done in the rewrite: the week, coming up, search and map, listing pages, still-on taps, email-link
sign-in, suggestions, the moderation queue, organiser claims, history, Surrey term dates.

Next, roughly in order:
1. **Deploy** to Vercel with Neon, set the secrets, restrict the Maps key, and look up map
   positions from postcodes.
2. **Ask the first users to confirm listings.** Everything starts as last checked in September
   2025.
3. **Email contributors** when a suggestion is approved or not used.
4. **A second area or kind of event**, to prove the model generalises. Areas, categories and
   term dates are data; a moderator screen to edit them would come with this.
5. **Accessibility details** on listings (step-free access, quiet sessions, SEND-friendly).
6. **Undo from the history** for moderators, restoring an earlier revision in one tap.
7. **Calendar export** (an .ics link per listing or filtered week).
